# Альфа tasks

Мобильный лендинг в формате Telegram Mini App: проверка участия, витрина заданий, выбор уровня награды, пошаговая инструкция и личный кабинет с заданиями в процессе.

**Рабочий URL:** https://alfa-w3ll.onrender.com

## Почему сайт «не открывался»

На бесплатном Web Service Render сервис **засыпает** после ~15 минут без запросов. При открытии из Telegram или браузера он просыпается 30–60 секунд — Telegram Mini App часто не ждёт и показывает ошибку.

## Исправление: статический хостинг

Сайт полностью статический (HTML + CSS + JS). Переведён на **Static Site** в Render — он **не засыпает**, раздаётся с CDN и открывается мгновенно.

### Что сделать в Render (один раз)

1. Зайдите в [Render Dashboard](https://dashboard.render.com)
2. Если уже есть Web Service `alfa-w3ll` / `alfa-tasks` — его можно удалить (или оставить как резерв).
3. **New → Static Site**
4. Подключите этот репозиторий (`karalik19-a11y/alfa`)
5. Настройки:
   - **Build Command:** `true` (или оставьте пустым)
   - **Publish Directory:** `.` (точка — корень репозитория)
6. Создайте сайт. После деплоя скопируйте новый URL (типа `https://alfa-xxxx.onrender.com`).
7. В BotFather укажите этот новый URL для Mini App.

Альтернатива через Blueprint: **New → Blueprint** и выберите репозиторий — `render.yaml` создаст Static Site автоматически.

## Запуск локально

Нужен Node.js 18+ (только для удобства локального сервера).

```bash
npm start
```

Откройте http://localhost:10000

## Где менять контент

- `app.js` — тексты экранов, ссылки и логика переходов.
- `styles.css` — визуальная система, мобильная адаптация, анимации и красно-белая тема.
- Ссылки для двух вариантов награды находятся в объекте `rewards` в начале `app.js`.

В Telegram WebApp профиль берётся из `Telegram.WebApp.initDataUnsafe.user`. При открытии в обычном браузере используется демо-профиль.
