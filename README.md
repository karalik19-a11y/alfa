# Альфа tasks

Мобильный лендинг в формате Telegram Mini App: проверка участия, витрина заданий, выбор уровня награды, пошаговая инструкция и личный кабинет с заданиями в процессе.

## Запуск локально

Нужен Node.js 18+.

```bash
npm install
npm start
```

После запуска откройте `http://localhost:10000`.

## Деплой на Render

В репозитории уже есть `render.yaml`. В Render можно выбрать **New + → Blueprint** и подключить репозиторий — сервис создастся с командой запуска `npm start` и будет слушать порт Render автоматически.

Если создавать Web Service вручную:

- **Runtime:** Node
- **Build command:** `npm install`
- **Start command:** `npm start`
- **Node:** 18 или новее

Сервер слушает `0.0.0.0` и использует `process.env.PORT`, поэтому подходит для Render.

## Где менять контент

- `app.js` — тексты экранов, ссылки и логика переходов.
- `styles.css` — визуальная система, мобильная адаптация, анимации и красно-белая тема.
- Ссылки для двух вариантов награды находятся в объекте `rewards` в начале `app.js`.

В Telegram WebApp профиль берётся из `Telegram.WebApp.initDataUnsafe.user`: отображаются имя, username и `photo_url`. При открытии в обычном браузере используется демо-профиль.
